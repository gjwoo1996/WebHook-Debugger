# To Do Web UI 개선 계획 (Web 버전)

## 1. 개요
`@app/(default-layout)/(web)/page.tsx`를 기준으로, `features/todo` 폴더 내의 컴포넌트들을 수정하여 요구사항을 반영합니다. `111.png` 이미지의 디자인과 동작을 웹 버전에 최적화하여 구현합니다.

## 2. 주요 작업 내용

### 2.1 상태 관리 전략 (`WebLayout` 및 `MainContent`)
- **선택된 작업 상태**: `app/(default-layout)/(web)/layout.tsx`를 클라이언트 컴포넌트로 전환하거나 전역 상태를 사용하여 `selectedTaskId`를 관리합니다. 이를 통해 `MainContent`에서의 클릭이 `TaskDetail` 사이드바의 표시 여부를 제어합니다.
- **작업 추가 상태**: `MainContent` 내부에서 `isAddingTask` 상태를 관리하여 입력창 포커스 시 버튼 레이어가 나타나도록 합니다.

### 2.2 `MainContent` 개선 (작업 목록 및 입력창)
- **작업 추가 레이어**: 입력창 클릭 시 하단에 [일정], [알림], [반복] 아이콘과 [추가] 버튼이 포함된 레이어를 구현합니다. (`111.png` 디자인 적용)
- **디자인 수정**: 목록 아이템의 스타일을 `111.png`와 유사하게 카드 형태로 개선합니다. (여백, 테두리, 아이콘 등)
- **클릭 외부 감지**: 입력창 외부 클릭 시 작업 추가 레이어가 닫히도록 구현합니다.

### 2.3 `TaskDetail` 개선 (상세 정보 사이드바)
- **조건부 표시**: `selectedTaskId`가 있을 때만 사이드바가 나타나도록 처리합니다.
- **디자인 고도화**: `111.png`의 상세 정보 영역 스타일을 반영하여 더욱 정교한 레이아웃을 구성합니다.
- **닫기 기능**: 사이드바 외부(MainContent 영역) 클릭 시 사이드바가 닫히도록 구현합니다.

## 3. 구현 순서

1.  **[Step 1] 레이아웃 리팩토링**: `app/(default-layout)/(web)/layout.tsx`에 작업 선택 상태(`selectedTaskId`)를 추가하고 클라이언트 컴포넌트로 변경합니다.
2.  **[Step 2] `MainContent` 인터랙션 구현**: 
    - "작업 추가" 포커스 시 레이어 표시 및 클릭 외부 감지 로직 추가.
    - 작업 목록 클릭 시 `onSelectTask` 호출 연동.
    - 목록 디자인 수정.
3.  **[Step 3] `TaskDetail` 연동 및 디자인**:
    - 선택된 작업 정보 표시 및 닫기 버튼/외부 클릭 닫기 구현.
    - 상세 정보 UI 정밀 조정.
4.  **[Step 4] 최종 검증**: 모든 클릭 외부 감지 및 토글 동작이 이미지와 일치하는지 확인합니다.

## 4. 기대 결과
- Microsoft To Do 웹 버전과 유사한 고품질 인터페이스 제공.
- 직관적인 작업 관리 및 상세 정보 열람 환경 구축.
