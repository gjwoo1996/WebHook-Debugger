# 협업 규칙

## 작업 규칙

- 작업 시작 전에 GitHub Issue를 생성
- 각 issue는 하나의 pull request로 리뷰할 수 있을 정도로 작게 유지
- 작업 시작과 완료 상태를 팀 커뮤니케이션 채널에 공유
- 2시간 이상 막히면 혼자 끌고 가지 말고 도움 요청
- 매주 30분 sync meeting 진행

## API 협업

- 구현 전에 API 동작을 먼저 논의
- 백엔드 변경에 맞춰 Swagger/OpenAPI 최신화
- 프론트엔드와 백엔드는 병렬 구현 전에 request/response 예시에 합의

## 리뷰 규칙

- 본인 pull request는 본인이 merge하지 않음
- 각 pull request는 최소 1명의 팀원이 리뷰
- pull request에는 변경 내용, 테스트 방법, UI 변경 시 screenshot 포함
