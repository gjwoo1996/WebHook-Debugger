# 일정 계획

## 4주 계획

| 주차 | 목표 |
| --- | --- |
| 1주차 | 모노레포 설정, ERD, API 계약, 로컬 개발 환경 |
| 2주차 | JWT 인증, endpoint CRUD, 웹훅 수신 흐름 |
| 3주차 | WebSocket 업데이트, 요청 재전송, 프론트엔드-백엔드 연동 |
| 4주차 | OCI 배포, Terraform, QA, 문서 마무리 |

## 위험 요소

- 인프라 작업은 예상보다 오래 걸릴 수 있으므로 Docker와 기본 배포 준비를
  가능하면 4주차 이전부터 시작
- 핵심 흐름이 안정화되기 전에는 소셜 로그인과 고급 검색을 MVP 밖에 둠
- 첫 데모는 endpoint 생성, 요청 수신, 요청 확인, 요청 재전송의 전체 경로를
  증명해야 함
