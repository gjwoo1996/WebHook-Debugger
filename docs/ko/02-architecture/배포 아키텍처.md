# 배포 아키텍처

## 배포 흐름

```text
GitHub Actions
  -> Docker image 빌드
  -> OCIR에 image push
  -> OCI Compute에서 image pull
  -> container 실행
  -> OCI Load Balancer를 통해 traffic routing
```

## 실행 구조

```text
OCI Load Balancer
  -> port 3000의 Next.js container
  -> port 8080의 Spring Boot container

OCI Compute Instance
  -> Next.js container
  -> Spring Boot container
  -> MVP 배포용 PostgreSQL container
```

## Terraform으로 관리하는 리소스

- VCN
- public/private subnet
- compute instance
- load balancer
- security list 또는 network security group rule
- 필요한 경우 container registry 접근 설정

## MVP 배포 참고

첫 1개월 프로젝트에서는 학습과 데모 목적상 PostgreSQL을 compute instance의
container로 실행해도 됩니다. 장기 운영 서비스가 된다면 managed database나
별도 backup 전략을 고려해야 합니다.
