# 기술 스택

## 스택

| 영역 | 기술 |
| --- | --- |
| 프론트엔드 | Next.js 14 with App Router |
| 백엔드 | Spring Boot 3.x |
| 데이터베이스 | PostgreSQL |
| 실시간 통신 | WebSocket with STOMP |
| 인증 | JWT |
| API 문서화 | Swagger with SpringDoc OpenAPI |
| 모노레포 | Turborepo |
| 인프라 | OCI and Terraform |
| CI/CD | GitHub Actions |
| 컨테이너 | Docker and Docker Compose |

## 이 선택이 적합한 이유

- Next.js는 현대적인 프론트엔드 구조와 실시간 클라이언트 화면에 적합함
- Spring Boot는 HTTP, security, persistence, WebSocket 지원이 안정적임
- PostgreSQL은 endpoint와 request history 저장에 실용적인 관계형 DB임
- 요청 수신은 브라우저에 즉시 보여야 하므로 WebSocket이 적합함
- JWT는 사용자별 endpoint와 history 접근을 stateless하게 보호함
- Swagger/OpenAPI는 프론트엔드와 백엔드 계약 논의에 유리함
- Docker와 Docker Compose는 로컬 개발 환경을 재현 가능하게 만듦
- Terraform과 OCI는 실제적인 인프라 학습을 제공함
