# 핵심 기능

## 인증

- 이메일 회원가입과 로그인
- JWT 기반 접근 제어
- MVP 안정화 이후 소셜 로그인 선택 적용

## Endpoint 관리

- UUID 기반 웹훅 수신 URL 발급
- 구분하기 쉬운 endpoint 이름 설정
- 더 이상 필요 없는 endpoint 삭제
- 임시 테스트 endpoint의 만료 시간 설정

## 요청 수신 및 시각화

- `GET`, `POST`, `PUT`, `PATCH`, `DELETE` 같은 주요 HTTP method 수신
- request method, path, query string, headers, body, IP, 수신 시각 저장
- JSON body를 읽기 쉬운 형태로 표시
- JSON이 아닌 body는 raw text로 표시
- WebSocket으로 브라우저에 실시간 알림

## 재전송

- 저장된 요청을 사용자가 입력한 대상 URL로 재전송
- 원본 body와 선택된 header 보존
- 재전송 status code와 응답 요약 표시
- 디버깅을 위해 재전송 시도 기록

## 히스토리

- endpoint별 수신 요청 목록 조회
- 요청 상세 조회
- HTTP method와 수신 날짜로 필터링
- 핵심 history 흐름 안정화 이후 기본 메타데이터 검색 추가
