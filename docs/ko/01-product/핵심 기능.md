# 핵심 기능

## 인증

- 이메일 회원가입과 로그인
- JWT 기반 접근 제어
- 빠른 진입 수단으로 소셜 로그인 제공

## 할 일 생성과 수정

- 로그인 후 할 일 목록 표시
- 한 줄 빠른 추가 입력창으로 할 일 추가
- 자세한 생성과 수정을 위한 상세 패널 제공
- 할 일 제목과 메모 수정
- 상세 패널에서 명시적으로 저장
- 저장하지 않은 변경사항이 있을 때 닫기 전 확인 안내

## 날짜, 우선순위, 반복

- 날짜 없음, 오늘, 내일, 직접 선택 지원
- 낮음, 보통, 높음 우선순위 지원
- 매일, 매주, 매월, 매년 단순 반복 지원
- 자연어 날짜 입력은 MVP에서 제외

## 정리

- 목록으로 할 일 분류
- 태그로 유연한 맥락 추가
- 첫 화면이 복잡해지지 않도록 태그는 상세와 고급 옵션에서 제공

## 보기

- 기본 일일 흐름을 위한 리스트 보기
- 날짜가 있는 할 일을 위한 캘린더 보기
- 상태 기반 관리를 위한 보드 보기
- 할 일 제목과 메모 검색을 위한 검색 모달

## 완료와 휴지통

- 할 일 완료 처리
- 완료한 당일에는 같은 목록에서 흐리게 표시
- 다음 날부터 완료한 할 일을 기본 목록 밖으로 이동
- 완료 취소 지원
- 삭제한 할 일은 즉시 삭제하지 않고 휴지통으로 이동
- 휴지통에서 복구와 영구 삭제 지원
