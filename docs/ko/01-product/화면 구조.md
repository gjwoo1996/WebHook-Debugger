# 화면 구조

## 개요

MVP는 데스크톱 웹 경험을 중심으로 구성합니다. 모바일 전용 화면은 첫 범위에
포함하지 않습니다.

로그인 후 첫 화면은 사용자의 현재 상태에 따라 달라집니다.

- 오늘 할 일이 있으면 오늘 할 일 목록을 먼저 보여줍니다.
- 오늘 할 일이 없으면 템플릿 선택지를 포함한 빠른 수집 빈 화면을 더
  눈에 띄게 보여줍니다.

## 로그인과 가입

- 이메일/비밀번호 로그인을 제공합니다.
- 빠른 진입 수단으로 소셜 로그인을 함께 제공합니다.
- 로그인 화면은 단순하게 유지합니다.
- 로그인 후에는 메인 할 일 화면으로 이동합니다.
- 계정 생성 직후 오늘 할 일이 없으면 빠른 수집 화면을 보여줍니다.

## 메인 할 일 화면

- 리스트 보기를 기본 진입점으로 사용합니다.
- 주요 필터는 접이식 왼쪽 사이드바에 둡니다.
- 오늘, 예정, 전체는 바로 표시합니다.
- 목록, 태그, 완료, 휴지통은 접힌 그룹이나 더보기 영역에 둡니다.
- 상단 보기 전환은 리스트, 캘린더, 보드 버튼으로 구성합니다.
- 오늘 할 일이 있으면 빠른 추가 입력창을 할 일 목록 아래에 둡니다.
- 오늘 할 일이 없으면 빠른 추가 입력창을 더 눈에 띄게 배치합니다.
- 할 일 행에는 체크박스, 제목, 날짜, 우선순위를 보여줍니다.
- 체크박스를 클릭하면 완료 처리합니다.
- 제목이나 행을 클릭하면 상세 패널을 엽니다.

## 할 일 상세 패널

- 데스크톱에서는 오른쪽 패널로 상세를 엽니다.
- 자세한 새 할 일 추가에도 같은 패널을 재사용합니다.
- 패널을 닫아도 사용자가 보던 목록 위치를 유지합니다.
- 변경사항은 패널 하단의 저장 버튼으로 저장합니다.
- 저장하지 않고 닫으려 할 때 변경사항이 있으면 확인 안내를 제공합니다.
- 삭제는 패널의 더보기 메뉴 안에 둡니다.
- 삭제한 할 일은 휴지통으로 이동하고 되돌리기 안내를 보여줍니다.

상세 필드 순서는 다음과 같습니다.

1. 제목
2. 날짜
3. 우선순위
4. 목록
5. 태그
6. 반복
7. 메모

## 검색 모달

- 검색 버튼은 왼쪽 사이드바에 둡니다.
- 검색은 화면 중앙 모달로 엽니다.
- 할 일 제목과 메모를 검색합니다.
- 최근 본 화면을 함께 보여줍니다.
- 검색 결과를 선택하면 관련 화면으로 이동하고 상세 패널을 엽니다.
- 빠른 이동 명령은 MVP에서 제외합니다.

## 캘린더 보기

- 월간 보기와 주간 보기를 제공합니다.
- 월간/주간 전환 버튼은 캘린더 오른쪽 상단에 둡니다.
- 날짜가 있는 할 일만 캘린더에 표시합니다.
- 날짜 없는 할 일은 리스트 보기와 사이드바 필터에서 확인합니다.
- 하루 칸에는 할 일을 1개만 직접 보여줍니다.
- 같은 날짜에 할 일이 더 있으면 `+N` 표시를 사용합니다.
- 할 일을 선택하면 오른쪽 상세 패널을 엽니다.

## 보드 보기

- 기본 컬럼은 할 일, 진행 중, 완료로 구성합니다.
- 보드는 우선순위나 목록이 아니라 진행 상태를 보는 화면입니다.
- 현재 선택된 사이드바 필터 안의 할 일만 보드에 표시합니다.
- 드래그 앤 드롭으로 상태를 변경할 수 있게 합니다.
- 드래그 앤 드롭을 쓰지 않는 사용자를 위해 상세 패널에서도 상태를 확인할 수
  있게 합니다.
- 보드 카드에는 제목, 날짜, 우선순위를 보여줍니다.
- 태그는 기본적으로 상세 패널에서 확인합니다.

## 완료와 휴지통

- 완료와 휴지통은 하나의 보관 화면 안에서 탭으로 구분합니다.
- 보관 화면은 사이드바 더보기 영역에서 엽니다.
- 기본 탭은 완료로 둡니다.
- 완료 탭에서는 완료 취소를 제공합니다.
- 휴지통 탭에서는 복구와 영구 삭제를 제공합니다.
