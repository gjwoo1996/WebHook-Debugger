# 서비스 흐름

## 주요 사용자 흐름

```text
1. 사용자가 회원가입 또는 로그인한다.
2. 앱이 메인 할 일 화면을 연다.
3. 오늘 할 일이 있으면 오늘 할 일 목록을 보여준다.
4. 오늘 할 일이 없으면 빠른 수집 빈 화면을 보여준다.
5. 사용자가 빠른 추가 또는 상세 패널로 할 일을 추가한다.
6. 사용자가 필요하면 날짜, 우선순위, 목록, 태그, 반복, 메모를 설정한다.
7. 사용자가 리스트, 캘린더, 보드 보기에서 할 일을 확인한다.
8. 사용자가 할 일을 완료하거나 보드 상태 컬럼 사이에서 이동한다.
9. 할 일이 많아지면 사용자가 검색 또는 필터를 사용한다.
10. 필요하면 완료하거나 삭제한 할 일을 복구한다.
```

## 할 일 생성 흐름

```text
빠른 추가 입력창 또는 상세 패널
  -> 할 일 검증
  -> 계정 기반 할 일 저장
  -> 리스트/캘린더/보드 화면 갱신
```

## 완료와 휴지통 흐름

```text
할 일
  -> 완료 또는 삭제 행동
  -> 당일 완료 상태 또는 휴지통 상태
  -> 완료 취소, 복구, 영구 삭제
  -> 기본 화면 갱신
```
