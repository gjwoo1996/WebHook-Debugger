# 서비스 흐름

## 주요 사용자 흐름

```text
1. 사용자가 회원가입 또는 로그인한다.
2. 사용자가 웹훅 endpoint를 생성한다.
3. 서비스가 공개 URL을 발급한다:
   https://webhookdebugger.com/hooks/{uuid}
4. 사용자가 해당 URL을 외부 서비스에 등록한다.
5. 외부 서비스가 디버거 URL로 이벤트를 보낸다.
6. 디버거가 요청을 저장한다.
7. 브라우저가 실시간 알림을 받는다.
8. 사용자가 method, headers, body, IP, 수신 시각을 확인한다.
9. 사용자가 저장된 요청을 선택한 대상 URL로 재전송한다.
10. 사용자가 재전송 응답 status와 결과를 확인한다.
```

## 요청 수신 흐름

```text
외부 서비스
  -> 공개 hook endpoint
  -> 요청 저장
  -> 실시간 WebSocket 이벤트
  -> 요청 상세 화면
```

## 재전송 흐름

```text
저장된 요청
  -> 사용자가 대상 URL 입력
  -> 백엔드가 재전송 요청 수행
  -> 백엔드가 재전송 결과 기록
  -> 브라우저가 status code와 응답 요약 표시
```
