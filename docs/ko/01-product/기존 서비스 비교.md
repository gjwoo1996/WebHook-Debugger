# 기존 서비스 비교

## 왜 기존 도구를 비교하는가?

Webhook.site, RequestBin, ngrok, Cloudflare Tunnel 같은 도구는 이미 웹훅
디버깅 문제의 일부를 해결합니다. 비교를 통해 무엇을 참고하고, 무엇을
무리하게 다시 만들지 않으며, 1개월 협업 프로젝트에서 어디에 집중할지 정할
수 있습니다.

## 비교

| 도구 | 장점 | 이 프로젝트 관점의 한계 |
| --- | --- | --- |
| Webhook.site | 빠른 공개 URL, 요청 확인, 쉬운 공유 | 이미 완성된 도구라 풀스택 구현 학습 목적과는 다름 |
| RequestBin | 단순한 요청 수집 개념 | 제공자에 따라 hosted version이 제한되거나 중단된 경우가 있음 |
| ngrok | 로컬 서버를 직접 외부에 노출, 통합 테스트에 좋음 | 저장된 요청 history와 replay UX가 핵심 목적은 아님 |
| Cloudflare Tunnel | 안정적인 tunnel 기반 로컬 서비스 접근 | 제품 기능보다 인프라 성격이 강함 |

## 프로젝트 포지셔닝

WebHook Debugger는 성숙한 도구들을 모든 영역에서 이기려는 프로젝트가
아닙니다. 학습 목표는 다음 흐름을 갖춘 집중된 제품을 만드는 것입니다.

- 인증 기반 endpoint 관리
- 저장된 요청 history
- 실시간 요청 시각화
- 저장된 요청 재전송
- 팀 협업에 적합한 문서와 개발 흐름
