# MVP 범위

프로젝트 기간은 약 1개월이고 인원은 2명입니다. MVP는 작지만 완결된 웹훅
디버깅 흐름에 집중합니다.

## 반드시 포함

- JWT 기반 회원가입과 로그인
- 웹훅 endpoint 생성, 목록, 이름 변경, 삭제
- endpoint별 공개 수신 URL
- 주요 HTTP method 요청 수신
- headers, body, method, path, IP, 수신 시각 저장
- 요청 목록과 요청 상세 화면
- 요청 수신 시 브라우저 실시간 알림
- 저장된 요청을 대상 URL로 재전송
- 로컬 개발용 Docker Compose 구성
- 프론트엔드와 백엔드 기본 CI 검사

## 가능하면 포함

- endpoint 만료 시간
- 요청 history의 method와 날짜 필터
- 재전송 결과 history
- 백엔드 API Swagger/OpenAPI 문서
- OCI 기본 production 배포

## 여유가 있으면 포함

- 소셜 로그인
- 고급 요청 검색
- 팀 공유
- 디버거 endpoint의 custom response status/body 설정
- 요청 JSON export

## 첫 1개월 범위에서 제외

- 결제 또는 유료 플랜
- 복잡한 역할 기반 권한
- multi-tenant 조직 관리
- 대용량 파일 upload payload 지원
- 전체 observability stack
- 브라우저 확장 프로그램 또는 데스크톱 앱
