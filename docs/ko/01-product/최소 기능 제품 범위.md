## 반드시 포함

- 회원가입과 로그인
- 계정 기반 서버 저장
- 할 일 목록 화면
- 한 줄 빠른 할 일 추가
- 할 일 생성과 수정을 위한 상세 패널
- 할 일 제목과 메모 입력
- 날짜 없음, 오늘, 내일, 직접 선택 날짜 옵션
- 낮음, 보통, 높음 우선순위
- 목록과 태그 정리
- 매일, 매주, 매월, 매년 단순 반복
- 리스트, 캘린더, 보드 보기
- 완료한 당일 흐리게 표시되는 완료 처리
- 완료 항목 되돌리기
- 휴지통, 복구, 영구 삭제
- 할 일 제목과 메모 검색
- 전체, 오늘, 예정, 완료, 중요, 목록, 태그 기본 필터
- 시작용 템플릿을 포함한 빈 화면
- 로컬 개발용 Docker Compose 구성
- 프론트엔드와 백엔드 기본 CI 검사

## 가능하면 포함

- 소셜 로그인
- 캘린더 월간 보기와 주간 보기
- 보드에서 드래그 앤 드롭으로 상태 변경
- 상세 패널의 저장하지 않은 변경사항 안내
- 백엔드 API 문서
- OCI 기본 production 배포

## 여유가 있으면 포함

- 저장 필터
- 자연어 날짜 입력
- 고급 반복 규칙
- 앱 내부 리마인더
- 선택적 브라우저 알림
- 다크 모드
- 화면 밀도 설정

## 첫 1개월 범위에서 제외

- 결제 또는 유료 플랜
- 팀 공유
- 담당자 지정
- 댓글과 활동 기록
- 위치 기반 리마인더
- 이메일 알림
- 서버 기반 Web Push
- 복잡한 개인화 설정
- 전체 observability stack
- 브라우저 확장 프로그램 또는 데스크톱 앱
