# 프로젝트 개요

## 요약

Simple TODO는 할 일을 빠르게 수집하고, 날짜, 목록, 태그, 우선순위로
정리하며, 리스트, 캘린더, 보드 화면에서 확인할 수 있는 웹 기반 TODO
앱입니다.

| 인프라 관리 | Terraform |

## 대상 사용자

- 복잡한 생산성 시스템을 먼저 배우지 않고 개인 할 일을 빠르게 적고 싶은 사용자
- 날짜, 목록, 태그, 우선순위, 반복 규칙으로 가볍게 할 일을 정리하고 싶은 사용자
- 인증, 저장, 검색, 필터, 풍부한 UI 상태, 배포를 함께 연습하려는 학습자

## 문제 정의

많은 TODO 앱은 너무 많은 개념을 너무 일찍 보여줍니다. 사용자는 먼저 오늘
할 일을 적을 공간이 필요하고, 구조화는 도움이 될 때 나중에 추가해도 됩니다.

Simple TODO는 할 일 수집, 필요한 날짜 결정, 선택적 정리, 완료와 삭제 실수
복구라는 기본 흐름을 단순하게 만들어 이 부담을 줄입니다.
