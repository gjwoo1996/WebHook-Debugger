# 프로젝트 개요

## 요약

WebHook Debugger는 공개 URL로 웹훅 요청을 수신하고, 브라우저에서 요청
내용을 확인하며, 저장된 요청을 로컬 또는 원격 서버로 다시 전송할 수 있게
해주는 개발자 도구입니다.

## 대상 사용자

- 결제, 로그인, 메시징, CI/CD, 알림 웹훅을 연동하는 개발자
- 최종 웹훅 핸들러를 만들기 전에 payload를 확인해야 하는 팀
- HTTP, 실시간 UI, 저장소, 인증, 배포를 함께 연습하려는 학습자

## 문제 정의

웹훅 연동은 로컬 개발 중에 어렵습니다. 외부 서비스는 개발자의
`localhost`로 직접 요청을 보낼 수 없기 때문입니다. 이로 인해 배포, 테스트,
확인, 수정, 재배포가 반복됩니다.

WebHook Debugger는 공개 수신 URL, 요청 저장, 실시간 표시, 요청 재전송
기능을 제공하여 이 반복 시간을 줄입니다.
