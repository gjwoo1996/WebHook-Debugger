# TODO 앱 사전 지식

## TODO 앱이란?

TODO 앱은 사용자가 할 일을 수집하고, 정리하고, 다음에 할 일을 고른 뒤,
끝낸 일을 완료 처리할 수 있게 돕는 도구입니다. 핵심 가치는 기능의 개수보다
매일의 할 일 흐름을 빠르고 명확하게 만드는 데 있습니다.

대표 개념은 다음과 같습니다.

- 할 일: 사용자가 기억하거나 끝내고 싶은 하나의 작업
- 날짜: 할 일을 처리해야 하는 시점
- 목록: 개인, 업무, 장보기처럼 할 일이 속한 큰 공간
- 태그: 전화, 외출, 공부처럼 유연하게 붙이는 맥락
- 우선순위: 더 중요한 일을 구분하는 단순한 신호
- 완료: 끝낸 일을 표시하되 되돌릴 수 있는 행동

## 흔한 사용자 요구

- 잊기 전에 할 일을 빠르게 적기
- 많은 설정 없이 오늘 할 일 확인하기
- 필요할 때만 날짜, 목록, 태그, 우선순위로 정리하기
- 예정된 일을 캘린더 형태로 확인하기
- 프로젝트성 일을 보드 형태로 관리하기
- 실수로 완료하거나 삭제한 일을 복구하기

## 설계 과제

TODO 앱은 날짜, 태그, 필터, 반복, 알림, 템플릿, 협업 같은 기능이 늘어나면서
쉽게 복잡해집니다. 이 프로젝트는 이런 기능을 선택적으로 열리는 단계로
다룹니다. 첫 화면은 단순하게 유지하고, 사용자가 필요할 때 더 깊은 기능을
사용할 수 있게 합니다.
