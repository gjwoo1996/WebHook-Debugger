# 학습 목표

## 프론트엔드

- Next.js App Router에서 Server Component와 Client Component를 실용적으로
  구분해 사용
- WebSocket 클라이언트로 실시간 요청 뷰어 구현
- TanStack Query로 서버 상태 관리
- JSON body를 읽기 쉬운 형태와 syntax highlighting으로 렌더링
- Axios 인터셉터 기반 공통 API 레이어를 만들고 인증/에러 처리 적용

## 백엔드

- 여러 HTTP method를 받을 수 있는 범용 웹훅 수신기 설계
- method, path, headers, body, IP, 수신 시각 같은 원본 요청 데이터 저장
- Spring Security와 JWT로 사용자별 endpoint와 history 보호
- JPA와 PostgreSQL로 endpoint와 request 관계 모델링
- method와 날짜 조건 기반 history 검색 구현
- WebClient로 저장된 요청을 재전송하고 중요한 요청 데이터 보존
- WebSocket과 STOMP로 올바른 브라우저 세션에 실시간 요청 이벤트 전달

## 인프라와 DevOps

- Docker로 프론트엔드와 백엔드 컨테이너 빌드
- Docker Compose로 로컬 개발 스택 실행
- GitHub Actions로 pull request 검사 자동화
- Oracle Cloud Infrastructure Registry에 이미지 푸시
- Terraform으로 OCI 네트워크, compute, load balancer, 보안 규칙 관리

## 협업

- 이슈 기반 개발 연습
- Swagger/OpenAPI를 프론트엔드와 백엔드의 공통 계약으로 사용
- pull request 리뷰 후 머지
- 풀스택 제품을 작고 테스트 가능한 작업으로 나누기
