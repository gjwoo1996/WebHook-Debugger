# 학습 목표

## 프론트엔드

- Next.js App Router에서 Server Component와 Client Component를 실용적으로
  구분해 사용
- TanStack Query로 할 일, 목록, 태그, 필터, 검색 상태 관리
- 할 일 목록, 상세 패널, 모달, 캘린더, 보드, 보관, 빈 화면 인터페이스 구현
- 날짜, 우선순위, 태그, 반복 규칙, 할 일 상태를 위한 접근 가능한 입력 컨트롤
  구현
- Axios 인터셉터 기반 공통 API 레이어를 만들고 인증/에러 처리 적용

## 백엔드

- Spring Security와 JWT로 보호되는 사용자별 할 일 API 설계
- JPA와 PostgreSQL로 할 일, 목록, 태그, 반복 규칙, 완료, 휴지통 상태 모델링
- 제목과 메모를 대상으로 한 할 일 검색 구현
- 전체, 오늘, 예정, 완료, 중요, 목록, 태그 필터 구현
- 완료 취소와 휴지통 복구가 가능한 흐름 구현

## 인프라와 DevOps

- Docker로 프론트엔드와 백엔드 컨테이너 빌드
- Docker Compose로 로컬 개발 스택 실행
- GitHub Actions로 pull request 검사 자동화
- Oracle Cloud Infrastructure Registry에 이미지 푸시
- Terraform으로 OCI 네트워크, compute, load balancer, 보안 규칙 관리

## 협업

- 이슈 기반 개발 연습
- API 문서를 프론트엔드와 백엔드의 공통 계약으로 사용
- pull request 리뷰 후 머지
- 풀스택 제품을 작고 테스트 가능한 작업으로 나누기
