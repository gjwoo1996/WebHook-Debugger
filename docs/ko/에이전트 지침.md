# 에이전트 지침

이 문서는 문서 트리에서 쉽게 확인할 수 있도록 루트의 `AGENTS.md` 내용을
한글로 옮긴 문서입니다.

## 스킬 사용 여부 표시

이 저장소에서 응답할 때는 스킬을 사용했는지 항상 표시합니다.

의미 있는 응답의 시작 부분에 다음 중 하나를 포함합니다.

- `사용 스킬: <skill-name>`
- `사용 스킬: 없음`

스킬을 사용했다면 왜 사용했는지도 짧게 설명합니다.

## 문서 언어 규칙

프로젝트 문서는 `docs/en`의 영문 문서를 원본으로 관리하고, `docs/ko`에
한글 번역본을 함께 둡니다.

프로젝트 문서를 추가하거나 수정할 때는 사용자가 한 언어만 요청하지 않는 한
두 언어 버전을 함께 갱신합니다.

`docs/ko` 아래의 한글 문서는 파일명도 한글로 작성합니다. `docs/en` 아래의
영문 문서는 영어 파일명을 유지합니다.
