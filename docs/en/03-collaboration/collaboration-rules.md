# Collaboration Rules

## Working Rules

- Create a GitHub Issue before starting work.
- Keep each issue small enough to review in one pull request.
- Share start and completion status through the team's communication channel.
- Do not spend more than 2 hours blocked without asking for help.
- Hold a 30-minute weekly sync meeting.

## API Collaboration

- Discuss API behavior before implementation.
- Keep Swagger/OpenAPI updated with backend changes.
- Frontend and backend work should agree on request and response examples before
  parallel implementation.

## Review Rules

- Do not merge your own pull request.
- At least one teammate should review each pull request.
- Pull requests should include what changed, how it was tested, and screenshots
  when UI changed.
