# Schedule

## Four-Week Plan

| Week | Goal |
| --- | --- |
| Week 1 | Monorepo setup, ERD, API contract, local development environment |
| Week 2 | JWT authentication, endpoint CRUD, webhook receiving flow |
| Week 3 | WebSocket updates, request replay, frontend-backend integration |
| Week 4 | OCI deployment, Terraform, QA, documentation polish |

## Risk Notes

- Infrastructure work often takes longer than expected. Start Docker and basic
  deployment preparation before week 4 when possible.
- Keep social login and advanced search outside the MVP unless the core flow is
  already stable.
- The first demo should prove the complete path: create endpoint, receive
  request, view request, replay request.
