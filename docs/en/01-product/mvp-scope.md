# MVP Scope

The project duration is approximately one month with two people. The MVP should
focus on a small but complete personal TODO flow.

## Must Have

- User sign-up and login.
- Server-side task storage by account.
- Task list screen.
- One-line quick task creation.
- Detail panel for task creation and editing.
- Task title and memo fields.
- Date options: no date, today, tomorrow, and direct selection.
- Priority options: low, normal, and high.
- List and tag organization.
- Simple repeat rules: daily, weekly, monthly, and yearly.
- List, calendar, and board views.
- Task completion with same-day dimming.
- Completed task recovery.
- Trash, restore, and permanent delete.
- Search task titles and memos.
- Basic filters: all, today, upcoming, completed, important, list, and tag.
- Empty states with starter templates.
- Docker Compose setup for local development.
- Basic CI checks for frontend and backend.

## Should Have

- Social login.
- Calendar monthly and weekly views.
- Board drag-and-drop for task status.
- Unsaved-change warning in the detail panel.
- API documentation for backend APIs.
- Basic production deployment to OCI.

## Could Have

- Saved filters.
- Natural-language date input.
- Advanced repeat rules.
- In-app reminders.
- Optional browser notifications.
- Dark mode.
- Density settings.

## Out of Scope for the First Month

- Billing or paid plans.
- Team sharing.
- Assignee management.
- Comments and activity logs.
- Location-based reminders.
- Email notifications.
- Server-based Web Push.
- Complex personalization settings.
- Full observability stack.
- Browser extension or desktop app.
