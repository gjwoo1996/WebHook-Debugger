Generated: 2026-05-26

## MVP Goal

사용자가 계정으로 로그인한 뒤, 할 일을 빠르게 추가하고, 날짜/목록/태그/우선순위로 정리하며, 리스트/캘린더/보드 화면에서 확인하고, 완료/삭제/복구까지 안전하게 처리할 수 있게 한다.

MVP는 웹 프로젝트 기준으로 설계한다. 모바일 앱 또는 모바일 전용 화면은 포함하지 않는다.

## MVP Features

### Account And Storage

- 로그인 기반 계정
- 서버 저장
- 여러 기기에서 같은 데이터 접근

### Task Creation And Editing

- 할 일 목록 보기
- 한 줄 빠른 추가
- 자세한 추가/상세 화면
- 할 일 수정
- 제목 입력
- 메모 입력

### Date And Repeat

- 날짜 없음
- 오늘
- 내일
- 직접 선택
- 단순 반복: 매일 / 매주 / 매월 / 매년

### Organization

- 목록 분류
- 태그
- 우선순위: 낮음 / 보통 / 높음

### Views

- 리스트 보기
- 캘린더 보기
- 보드 보기

### Completion And Trash

- 할 일 완료 처리
- 완료 항목은 당일 흐리게 표시
- 다음 날부터 완료 목록으로 이동
- 완료 항목 되돌리기
- 휴지통 이동
- 휴지통에서 복구
- 휴지통에서 영구 삭제

### Search And Filters

- 검색
- 기본 필터: 전체
- 기본 필터: 오늘
- 기본 필터: 예정
- 기본 필터: 완료
- 기본 필터: 중요
- 기본 필터: 목록별
- 기본 필터: 태그별

### Empty States

- 기본 빈 화면 안내
- 템플릿 기반 빈 화면
- 예시 템플릿: 장보기 목록
- 예시 템플릿: 공부 계획
- 예시 템플릿: 업무 할 일
- 예시 템플릿: 병원/예약 일정

## MVP UX Rules

- 첫 진입 화면은 리스트 보기로 시작한다.
- 캘린더와 보드는 보기 전환으로 접근한다.
- 태그는 처음부터 과하게 노출하지 않고 상세/추가 옵션에서 자연스럽게 제공한다.
- 삭제는 즉시 영구 삭제하지 않는다.
- 완료한 할 일은 당일에는 확인 가능해야 한다.
- 저장 필터처럼 조건 조합이 필요한 기능은 MVP에서 제외한다.
