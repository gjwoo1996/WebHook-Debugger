# Screen Structure

Generated: 2026-05-26

## Purpose

MVP 기능을 어떤 화면에 배치할지 정리한다.

이 문서는 화면 구성 회의의 1차 결정 내용을 정리한다.

## Candidate Screens

### 1. Login / Signup

사용자가 계정으로 들어오는 화면이다.

결정:

- 이메일/비밀번호 로그인을 제공한다.
- 소셜 로그인을 함께 제공한다.
- 로그인/가입 화면은 단순하게 유지한다.
- 로그인 후에는 메인 할 일 화면으로 이동한다.
- 계정 생성 직후 오늘 할 일이 없으면 빠른 수집 화면을 보여준다.

사용성 원칙:

- 사용자가 앱을 쓰기 전에 긴 설정을 요구하지 않는다.
- 로그인 화면에서는 핵심 가치와 진입 버튼만 명확하게 보여준다.
- 소셜 로그인은 빠른 진입 수단으로 제공하되, 이메일/비밀번호도 지원한다.

### 2. Main Task Screen

기본 진입 화면이다.

결정:

- 오늘 할 일이 있으면 오늘 할 일 중심 화면을 보여준다.
- 오늘 할 일이 없으면 빠르게 할 일을 적어둘 수 있는 수집 화면을 보여준다.
- 즉, 첫 화면은 사용자의 현재 상태에 따라 실행 중심 또는 수집 중심으로 전환된다.
- 오늘 할 일이 없는 수집 화면에는 큰 입력창과 템플릿 버튼을 보여준다.
- 최근 완료/예정 요약은 수집 화면에 넣지 않는다.

사용성 원칙:

- 할 일이 있는 사용자는 바로 체크하고 실행할 수 있어야 한다.
- 할 일이 없는 사용자는 빈 화면에서 멈추지 않고 바로 추가할 수 있어야 한다.
- 오늘 할 일이 없더라도 전체 목록, 예정, 캘린더, 보드로 이동할 수 있어야 한다.
- 메인 상단에는 제목, 남은 할 일 수, 보기 전환을 보여준다.
- 정렬 버튼은 MVP 상단 영역에 두지 않는다.
- 빠른 추가 입력창은 할 일 목록 아래에 둔다.
- 사용자가 현재 할 일을 먼저 확인한 뒤 자연스럽게 새 할 일을 추가할 수 있게 한다.
- 오늘 할 일이 없는 수집 화면에서는 입력창을 더 눈에 띄게 배치한다.
- 빠른 추가 입력창에는 제목 입력, 날짜 버튼, 우선순위 버튼, 추가 버튼을 제공한다.
- 사용자는 Enter로 바로 추가할 수 있고, 버튼으로도 추가할 수 있다.
- 날짜와 우선순위는 작은 보조 버튼으로 제공해 화면을 복잡하게 만들지 않는다.
- 할 일 목록 한 줄에는 체크박스, 제목, 날짜, 우선순위를 기본으로 보여준다.
- 목록과 태그는 기본 행에서 과하게 드러내지 않고 상세 패널에서 확인한다.
- 할 일 제목 또는 행을 클릭하면 오른쪽 상세 패널을 연다.
- 체크박스를 클릭할 때만 완료 처리한다.
- 상세 열기와 완료 처리를 명확히 분리해 실수를 줄인다.
- 기본 필터는 왼쪽 사이드바에 둔다.
- 검색 버튼은 왼쪽 사이드바에 둔다.
- 검색 버튼을 누르면 화면 중앙에 검색 모달을 띄운다.
- 검색 모달은 할 일 검색 결과와 최근 본 화면을 제공한다.
- 빠른 이동 명령은 MVP 검색 모달에서 제외한다.
- 검색 모달에는 단축키 힌트를 표시할 수 있다.
- 검색 결과를 클릭하면 해당 할 일이 속한 화면으로 이동하고 오른쪽 상세 패널을 연다.
- 예: 오늘 할 일을 검색 결과에서 클릭하면 오늘 화면으로 이동한 뒤 상세 패널을 연다.
- 보기 전환은 상단에 둔다.
- 필터는 "무엇을 볼지"를 정하고, 보기 전환은 "어떻게 볼지"를 정한다.
- 왼쪽 사이드바는 접이식 구조로 간소화한다.
- 오늘 / 예정 / 전체은 바로 표시한다.
- 목록 / 태그 / 완료 / 휴지통은 접힌 영역이나 더보기 안에 둔다.
- 화면의 중심은 사이드바가 아니라 오늘 할 일 목록이어야 한다.

추가 결정:

- 상단 보기 전환의 구체적인 버튼 구성
- 접힌 목록/태그를 어떻게 펼칠지

### Top View Switch

결정: 아이콘 + 텍스트 버튼을 사용한다.

- 보기 전환은 상단에 둔다.
- 버튼은 리스트, 캘린더, 보드로 구성한다.
- 아이콘만 사용하지 않고 텍스트를 함께 제공한다.
- 처음 사용하는 사용자도 각 버튼의 의미를 이해할 수 있어야 한다.

### Collapsible Sidebar Groups

결정: 목록과 태그는 클릭하면 사이드바 안에서 아래로 펼친다.

- 목록과 태그는 기본적으로 접힌 상태로 둔다.
- 사용자가 목록 또는 태그를 클릭하면 같은 사이드바 안에서 하위 항목이 펼쳐진다.
- 팝오버나 별도 화면으로 이동하지 않는다.
- 펼친 상태에서도 오늘/예정/전체 항목은 계속 보이게 한다.
- 하위 항목이 많아지면 일부만 보여주고 "더 보기"를 제공한다.

### 3. Task Detail

할 일의 세부 정보를 보는 화면이다.

결정:

- 데스크톱에서는 오른쪽 패널로 연다.
- 상세 패널은 할 일을 선택했을 때만 열린다.
- 목록, 캘린더, 보드에서 할 일을 선택하면 같은 상세 패널을 사용한다.
- 새 할 일을 자세히 추가할 때도 같은 패널 구조를 재사용한다.
- 이 프로젝트는 웹 프로젝트이므로 모바일 전용 상세 화면은 설계하지 않는다.

사용성 원칙:

- 사용자는 목록 맥락을 잃지 않고 할 일을 수정할 수 있어야 한다.
- 여러 할 일을 연속으로 확인하거나 수정하기 쉬워야 한다.
- 패널을 닫으면 원래 보던 목록 위치가 유지되어야 한다.
- 상세 패널의 변경사항은 저장 버튼을 눌러 저장한다.
- 저장 버튼은 패널 하단에 둔다.
- 저장하지 않고 닫으려 할 때 변경사항이 있으면 확인 안내를 제공한다.
- 삭제 버튼은 패널 상단 더보기 메뉴 안에 둔다.
- 삭제는 휴지통 이동으로 처리한다.
- 삭제 직후 되돌리기 안내를 제공한다.

추가 결정:

- 메모, 날짜, 반복, 목록, 태그, 우선순위를 어떻게 배치할지

상세 패널 정보 배치:

1. 제목
2. 날짜
3. 우선순위
4. 목록
5. 태그
6. 반복
7. 메모

실행에 중요한 날짜와 우선순위를 위에 두고, 메모는 아래에 둔다.

상세 패널 날짜 입력:

- 날짜 없음 / 오늘 / 내일 / 직접 선택 버튼을 먼저 보여준다.
- 직접 선택을 누르면 날짜 선택기를 연다.
- MVP에서는 자연어 날짜 입력을 제공하지 않는다.

상세 패널 우선순위 입력:

- 낮음 / 보통 / 높음 버튼 그룹으로 제공한다.
- 기본값은 보통이다.
- 색상만으로 구분하지 않고 텍스트를 함께 표시한다.

상세 패널 목록/태그 입력:

- 목록은 드롭다운/선택 메뉴로 고른다.
- 태그는 검색/추가 입력으로 고른다.
- 태그는 기존 태그를 검색하거나 새 태그를 추가할 수 있어야 한다.

상세 패널 반복 입력:

- 반복 설정은 드롭다운으로 선택한다.
- 기본값은 반복 안 함이다.
- 선택지는 반복 안 함 / 매일 / 매주 / 매월 / 매년으로 둔다.
- 반복은 날짜, 우선순위보다 덜 자주 쓰는 항목이므로 버튼 그룹으로 크게 노출하지 않는다.
- 드롭다운 라벨에는 현재 선택값을 보여준다.

### 4. Calendar View

날짜 기준으로 할 일을 확인하는 화면이다.

결정:

- MVP에서 월간 보기와 주간 보기를 모두 제공한다.
- 월간 보기는 한 달 단위로 할 일 분포를 훑는 용도다.
- 주간 보기는 가까운 일정과 이번 주 할 일을 집중해서 보는 용도다.
- 캘린더에서 할 일을 선택하면 오른쪽 상세 패널이 열린다.
- 날짜 없는 할 일은 캘린더에 표시하지 않는다.
- 날짜 없는 할 일은 목록 화면이나 사이드바 필터에서 확인한다.
- 캘린더의 하루 칸에는 할 일을 1개만 직접 보여준다.
- 같은 날 할 일이 더 있으면 +N 형태로 표시한다.

추가 결정:

- 없음

월간/주간 보기 전환:

- 월간/주간 보기 전환 버튼은 캘린더 오른쪽 상단에 둔다.
- 이 전환은 캘린더 화면 안에서만 의미가 있으므로, 전체 보기 전환과 분리해 캘린더 내부 컨트롤로 제공한다.
- 사용자는 캘린더 화면 안에서 현재 월간 보기인지 주간 보기인지 바로 확인할 수 있어야 한다.

### 5. Board View

진행 단계별로 할 일을 확인하는 화면이다.

결정:

- 보드의 기본 컬럼은 할 일 / 진행 중 / 완료로 구성한다.
- 보드는 우선순위나 목록이 아니라 진행 상태를 보는 화면이다.
- 보드에서 할 일을 선택하면 오른쪽 상세 패널이 열린다.
- 완료 컬럼의 항목도 완료 처리 규칙을 따른다.
- 보드는 현재 선택된 필터 안에서만 보여준다.
- 예: 왼쪽에서 "업무"를 선택한 뒤 보드로 전환하면 업무 할 일만 보드로 표시한다.
- 왼쪽 필터는 "무엇을 볼지", 상단 보기 전환은 "어떻게 볼지"라는 원칙을 유지한다.
- 보드에서 할 일 상태는 드래그 앤 드롭으로 컬럼을 이동해서 변경한다.
- 드래그 앤 드롭이 어려운 환경을 위해 상세 패널에서도 현재 상태를 확인할 수 있게 한다.
- 보드 카드에는 제목, 날짜, 우선순위를 보여준다.
- 태그는 보드 카드에 기본 노출하지 않고 상세 패널에서 확인한다.

추가 결정:

- 완료 목록과 휴지통 화면 구성

### 6. Completed And Trash

완료된 할 일과 삭제된 할 일을 확인하는 화면이다.

결정:

- 보관 화면 하나 안에 완료 / 휴지통 탭을 제공한다.
- 사이드바 더보기에서 보관 화면으로 접근한다.
- 보관 화면의 기본 탭은 완료로 둔다.
- 휴지통 탭에서는 복구와 영구 삭제를 제공한다.
- 완료 탭에서는 완료 취소를 제공한다.

사용성 원칙:

- 자주 쓰지 않는 완료/휴지통 기능은 메인 화면에서 과하게 드러내지 않는다.
- 삭제와 완료를 같은 "보관" 맥락으로 묶어 사이드바를 깔끔하게 유지한다.
- 복구 가능한 항목임을 명확히 보여준다.
