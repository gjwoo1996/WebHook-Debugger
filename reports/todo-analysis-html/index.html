Notion 내용을 먼저 읽기 좋게 정리한 회의용 HTML

이 문서는 아직 기획 결론을 내리지 않습니다. TickTick과 Todoist 분석 내용을 기능 트리와 UX 관찰로 나누어, 이후 회의에서 “우리 프로젝트에 어떤 TODO 기능을 구현할지” 함께 판단하기 위한 자료입니다.

현재 단계의 목표

해석과 결론을 최소화하고, Notion의 원문 구조를 보기 쉽게 재배치했습니다. 다음 단계에서 이 내용을 기준으로 MVP, 확장 기능, 후순위 기능을 함께 나누면 됩니다.

회의 진행용 관점

아래 세 질문만 들고 읽으면 기획 회의가 훨씬 선명해집니다. 아직 답을 확정하지 않고, 원문을 보며 후보를 표시하는 용도입니다.

1. 반드시 있어야 하는 기능은?

할 일 생성, 완료, 날짜, 목록처럼 TODO 앱으로 인식되기 위한 최소 기능을 찾습니다.

2. 차별화에 도움 되는 기능은?

자연어 입력, 캘린더, 보드, 반복 작업, 템플릿처럼 나중에 강점이 될 후보를 분리합니다.

3. 지금은 미뤄도 되는 기능은?

협업, 위치 알림, 포모도로, 습관, 통계처럼 초기 범위를 키우는 기능을 가려냅니다.

TickTick 기능 트리

Notion의 TickTick 섹션 중 “1. 기능 트리”를 기능 영역별로 정리했습니다.

TODO Calendar Habit Pomodoro

1.1 할 일 생성

  • 기본 작업 추가
    • 할 일 제목 입력
    • 설명/메모 입력
    • 빠른 추가 입력창 사용
    • 입력 후 즉시 목록에 등록
  • 자연어 입력
    • 오늘, 내일, 다음 주 같은 날짜 표현 입력
    • 특정 시간 입력
    • 반복 일정 입력
    • 입력 중 날짜/시간 자동 인식
  • 상세 정보 추가
    • 마감일, 마감 시간, 우선순위 설정
    • 태그, 리스트, 담당자 지정
  • 하위 작업 생성
    • 큰 작업을 작은 단위로 분해
    • 체크리스트 형태로 단계 관리

1.2 날짜/일정 관리

  • 날짜 설정
    • 오늘, 내일, 이번 주, 다음 주
    • 특정 날짜, 날짜 없음
  • 시간/기간 설정
    • 특정 시각, 하루 종일 작업
    • 시작 시간, 종료 시간
    • 일정처럼 캘린더에 배치
  • 반복 작업 설정
    • 매일, 매주, 매월, 매년
    • 사용자 지정 반복
    • 완료일 기준 반복
  • 캘린더 보기
    • 할 일을 날짜 기반으로 확인
    • 일정과 할 일을 함께 확인
    • 드래그 앤 드롭으로 일정 재배치

1.3 리스트/프로젝트 구조화

  • 리스트 생성
    • 개인, 업무, 쇼핑, 공부, 사이드 프로젝트 리스트
  • 리스트별 작업 관리
    • 관련 작업을 한 공간에 모음
    • 리스트 단위로 작업 확인
    • 리스트 단위로 공유 가능
  • 폴더 구조
    • 여러 리스트를 상위 폴더로 묶음
    • 개인/업무/학습/사이드 프로젝트 구분
  • 작업 순서 정리
    • 드래그 앤 드롭으로 순서 변경
    • 중요 작업 상단 배치

1.4 보기 방식

  • 리스트 보기
    • 작업을 위에서 아래로 확인
    • 단순한 할 일 처리에 적합
  • 캘린더 보기
    • 날짜 기반으로 작업 확인
    • 시간대별 계획 수립 가능
  • 칸반/보드형 보기
    • 단계별 작업 상태 파악
    • 진행 흐름이 있는 프로젝트에 적합
  • Today 보기와 Next 7 Days 보기
    • 오늘 해야 할 일 집중
    • 앞으로 일주일 작업 확인

1.5 분류/탐색

  • 태그
    • 작업에 맥락 부여
    • 리스트와 상관없이 작업을 묶음
    • 예: 회의, 외부, 집중, 확인 필요
  • 스마트 리스트/필터
    • 날짜, 태그, 우선순위, 리스트, 완료 여부 기준 필터
  • 검색
    • 작업명, 메모, 태그, 완료된 작업 검색
  • 즐겨찾기/고정
    • 자주 쓰는 리스트, 태그, 보기 방식 빠르게 접근

1.6 우선순위/실행 관리

  • 우선순위 설정
    • 높음, 중간, 낮음, 없음
  • 우선순위 시각 표시
    • 색상 또는 아이콘으로 중요도 구분
  • 작업 완료
    • 체크박스로 완료 처리
    • 하위 작업 개별 완료
    • 반복 작업의 이번 회차 완료
  • 미완료 작업 조정
    • 날짜 변경, 우선순위 변경, 리스트 이동, 삭제 또는 보류

1.7 협업 기능

  • 리스트 공유
    • 가족, 팀원, 프로젝트 멤버와 공유
  • 작업 할당
    • 담당자 지정
    • 공유 리스트 내 역할 분배
  • 댓글/활동 기록
    • 작업별 코멘트 작성
    • 진행 상황 공유, 변경 내역 확인
  • 협업 알림
    • 담당 작업, 댓글, 공유 리스트 변경 알림

1.8 알림/리마인더

  • 시간 기반 알림
    • 특정 시간, 마감 전, 반복 작업 알림
  • 다중 알림
    • 사전 알림, 마감 시간 알림, 반복 알림
  • 위치 기반 알림
    • 특정 장소 도착 또는 이탈 시 알림
  • 알림 채널과 역할
    • 앱, 기기별, 이메일 알림 가능성
    • 작업 망각 방지, 앱 재방문 유도, 마감 기반 실행 강화

1.9 템플릿/자동화

  • 템플릿 사용
    • 반복적으로 쓰는 리스트 구조 재사용
    • 개인 생산성, 업무 관리, 학습/생활 관리 템플릿
  • 반복 업무 자동화
    • 반복 할 일 생성
    • 정기 루틴 자동 생성
    • 완료 기준 반복 설정
  • 실행 보조 기능
    • 포모도로 타이머
    • 집중 시간 기록과 세션 통계
  • 외부 연동
    • 캘린더, 이메일, 브라우저 확장, 여러 기기 동기화

1.10 개인화/설정

  • 테마 설정
    • 라이트 모드, 다크 모드, 색상 테마, 보기 방식 조정
  • 알림 설정
    • 기본 알림 시간, 반복 알림 방식, 기기별 알림
  • 작업 기본값
    • 기본 리스트, 기본 날짜, 기본 우선순위, 기본 알림
  • 계정/플랜과 생산성 보조 설정
    • 무료/유료 플랜, 프리미엄 기능
    • 습관 추적, 포모도로, 통계 확인 방식

TickTick UX 관점에서 부족한 부분

Notion의 TickTick 섹션 중 “2. UX 관점에서 부족한 부분”을 접이식 항목으로 정리했습니다.

2.1 첫 진입 경험
  • 핵심 타깃 사용자가 개인, 팀, 학생, 직장인, 프리랜서 중 누구인지 더 명확해야 함
  • 단순 TODO 앱과의 차별점이 첫 화면에서 즉시 드러나야 함
  • 개선 방향: “할 일 수집 → 일정화 → 실행 → 회고” 흐름, 사용자 유형별 사례, 샘플 화면 제공
2.2 기능 발견성
  • 스마트 리스트, 고급 반복, 매트릭스, 캘린더 구독, 포모도로, 습관 추적, 통계가 숨어 있을 가능성
  • 기능을 모르면 단순 TODO 앱처럼만 사용할 수 있음
  • 개선 방향: 상황 기반 추천, 빈 화면 안내, 반복 행동 감지 시 자동화 제안
2.3 리스트/태그/스마트 리스트의 개념 구분
  • 리스트, 폴더, 태그, 스마트 리스트의 역할 차이를 초보자가 이해하기 어려움
  • 분류 체계를 잘못 만들면 나중에 정리가 어려워짐
  • 개선 방향: 첫 리스트 생성 시 가이드, 예시 기반 설명, 추천 구조 제공
2.4 날짜 기반 사용 흐름의 압박감
  • Today 중심 구조는 집중에 유리하지만 작업이 많아지면 압박감이 커짐
  • 미완료 작업 누적과 과도한 알림이 피로를 만들 수 있음
  • 개선 방향: Today 작업 자동 정리 제안, 미완료 작업 재배치, 심리적 완충 UX
2.5 보기 방식의 전환 맥락
  • 리스트, 캘린더, 보드, 매트릭스는 서로 다른 사고방식을 요구함
  • 어떤 상황에 어떤 보기를 써야 하는지 모를 수 있음
  • 개선 방향: 목적별 추천 보기, 보기 전환 안내, 초보자는 기본 리스트/Today 중심으로 시작
2.6 협업 기능의 포지셔닝
  • 개인 생산성 앱 인식이 강하고, 팀 협업에서는 권한/리포트/의존성 관리가 부족해 보일 수 있음
  • 개선 방향: 개인용/팀용 사례 분리, 가족/소규모 팀 중심 포지셔닝, 경쟁 도구와 차이 설명
2.7 무료/유료 기능 경계
  • 캘린더, 습관, 포모도로, 고급 필터, 반복 알림, 협업의 무료/유료 경계가 중요함
  • 사용하려는 순간 유료 제한을 만나면 실망 가능
  • 개선 방향: 기능 설정 화면에서 사전 표시, 가격 페이지 비교표 강화, 무료 대안 제시
2.8 알림 피로도
  • 마감일, 반복 작업, 습관, 팀 댓글, 여러 기기 동기화에서 알림이 많아질 수 있음
  • 중요한 알림과 덜 중요한 알림이 섞이면 무시하게 됨
  • 개선 방향: 알림 우선순위, 조용한 시간대, 중요 작업만 알림, 알림 빈도 추천
2.9 빈 상태 화면
  • Inbox, Today, 리스트, 태그, 습관, 검색 결과가 비어 있을 수 있음
  • 개선 방향: 단순한 빈 화면 대신 다음 행동, 예시 작업, 템플릿, 기능 설명 연결 제공
2.10 접근성
  • 우선순위를 색상만으로 구분하면 한계가 있음
  • 빠른 추가, 날짜 변경, 완료 처리 단축키 안내가 중요함
  • 정보 밀도 조절 옵션도 필요함
2.11 차별점 표현
  • Todoist, Microsoft To Do, Google Tasks, Notion, Asana/Trello와 비교됨
  • TickTick 강점: TODO + Calendar + Habit + Pomodoro + Matrix 통합, 계획/실행/회고 결합
  • 개선 방향: “계획·실행·회고를 하나로 통합” 메시지, 비교표, 사용자 유형별 추천 사용법

TickTick 개선 우선순위

  1. 1첫 진입 메시지와 CTA 명확화
  2. 2리스트, 태그, 스마트 리스트 개념 구분 강화
  3. 3고급 기능 발견성 개선
  4. 4무료/유료 기능 경계 명확화
  5. 5Today 과부하와 알림 피로도 완화

Todoist 기능 트리

Notion의 Todoist 섹션 중 “1. 기능 트리”를 기능 영역별로 정리했습니다.

Quick Add Projects Filters Board

1.1 할 일 생성

  • 기본 작업 추가
    • 작업명 입력, 설명 입력, 빠른 추가 입력창 사용, Enter 기반 빠른 등록
  • 자연어 입력
    • 오늘, 내일, 다음 주, 특정 시간, 반복 일정, 입력 중 날짜/시간 자동 인식
  • 상세 정보 추가
    • 마감일, 마감 시간, 우선순위, 라벨, 프로젝트, 섹션, 담당자 지정
  • 하위 작업 생성
    • 큰 작업을 작은 단위로 분해하고 단계별 체크 가능

1.2 날짜/일정 관리

  • 날짜 설정
    • 오늘, 내일, 이번 주, 다음 주, 특정 날짜, 날짜 없음
  • 반복 작업 설정
    • 매일, 매주, 매월, 매년, 사용자 지정 반복
  • 예정 화면
    • 오늘 해야 할 일, 앞으로 예정된 작업, 날짜별 작업 흐름 파악
  • 캘린더 보기
    • 작업을 날짜 기반으로 확인하고 일정처럼 배치

1.3 프로젝트 구조화

  • 프로젝트 생성
    • 개인, 업무, 공부, 사이드 프로젝트, 팀 프로젝트
  • 프로젝트별 작업 관리
    • 관련 작업을 한 공간에 모으고 프로젝트별 진행 상황 파악
  • 섹션 생성
    • 할 일/진행 중/완료, 기획/디자인/개발/배포 등 단계 구분
  • 작업 순서 정리
    • 드래그 앤 드롭, 중요한 작업 상단 배치, 실행 순서 기준 정리

1.4 보기 방식

  • 리스트 보기
    • 단순한 할 일 관리, 빠른 입력과 체크에 유리
  • 보드 보기
    • 칸반 형태로 작업 확인, 섹션별 작업 상태 파악
  • 캘린더 보기
    • 날짜 기반 작업 확인, 일정 계획에 적합
  • Today / Upcoming 보기
    • 오늘 해야 할 일과 앞으로 예정된 작업 확인

1.5 분류/탐색

  • 라벨
    • 작업에 맥락 부여, 프로젝트와 상관없이 작업 묶음
  • 필터
    • 날짜, 라벨, 우선순위, 담당자 기준 조건 목록 생성
  • 검색
    • 작업명, 설명, 완료된 작업 검색
  • 즐겨찾기
    • 자주 쓰는 프로젝트와 필터 고정

1.6 우선순위/실행 관리

  • 우선순위 설정
    • P1, P2, P3, P4
  • 우선순위 시각 표시
    • 색상으로 중요도 구분
  • 작업 완료
    • 체크박스로 완료 처리, 완료된 작업 숨김, 완료 기록 확인
  • 미완료 작업 조정
    • 날짜 변경, 우선순위 변경, 프로젝트 이동, 삭제 또는 보류

1.7 협업 기능

  • 프로젝트 공유
    • 다른 사용자 초대, 공동 작업 공간 생성, 팀/가족/소규모 프로젝트 관리
  • 작업 할당
    • 담당자 지정, 팀 작업 분배
  • 댓글
    • 작업별 커뮤니케이션, 진행 상황 공유, 작업 맥락 유지
  • 알림
    • 담당 작업 변경, 댓글, 마감 관련 알림

1.8 알림/리마인더

  • 시간 기반 리마인더
    • 특정 시간, 마감 전, 반복 작업 알림
  • 위치 기반 리마인더
    • 특정 장소 도착 또는 이탈 시 알림
  • 알림 채널
    • 앱 알림, 이메일 알림, 기기별 알림
  • 알림의 역할
    • 작업 망각 방지, 앱 재방문 유도, 마감 기반 실행 강화

1.9 템플릿/자동화

  • 템플릿 사용
    • 반복 프로젝트 구조, 개인 생산성, 업무 관리, 교육/학습 템플릿
  • 프로젝트 템플릿 생성
    • 기존 프로젝트 구조 저장, 동일한 업무 프로세스 재사용
  • 외부 연동
    • 캘린더, 이메일, 자동화 도구, 다른 생산성 도구와 연결

1.10 개인화/설정

  • 테마 설정
    • 라이트 모드, 다크 모드, 색상 테마
  • 알림 설정
    • 기본 알림 방식, 이메일 알림, 푸시 알림
  • 계정/플랜 관리
    • 무료 플랜, 유료 플랜, 팀 플랜
  • 사용 환경 설정
    • 언어 설정, 시간대 설정, 시작 화면 설정

Todoist UX 관점에서 부족한 부분

Notion의 Todoist 섹션 중 “2. UX 관점에서 부족한 부분”을 접이식 항목으로 정리했습니다.

2.1 첫 진입 경험
  • 로그인/가입 전 제품 이해가 제한될 수 있음
  • 실제 앱 진입 URL에서는 계정 생성이 기능 탐색보다 먼저 노출될 수 있음
  • 개선 방향: 로그인 전 샘플 워크스페이스, 대표 사용 흐름, 체험하기 또는 샘플 프로젝트 보기
2.2 기능 발견성
  • 필터, 라벨, 보드 보기, 템플릿, 반복 날짜 자연어 입력, 위치 기반 리마인더가 숨어 있을 수 있음
  • 초보자는 단순 체크리스트 앱처럼만 사용할 수 있음
  • 개선 방향: 빈 화면 기능 추천, 사용 패턴 기반 제안, 빠른 추가 입력창의 자연어 예시
2.3 프로젝트/섹션/라벨/필터의 개념 구분
  • 프로젝트, 섹션, 라벨, 필터의 역할 차이가 헷갈릴 수 있음
  • 필터는 강력하지만 설정 진입 장벽이 높을 수 있음
  • 개선 방향: 첫 프로젝트 생성 시 가이드, 라벨과 필터 예시, 추천 구조 제공
2.4 날짜 기반 사용 흐름의 압박감
  • Today 중심 구조는 집중에 유리하지만 작업이 많아지면 압박감이 커짐
  • 일정 관리보다 마감 관리처럼 느껴질 수 있음
  • 개선 방향: Today 작업 자동 정리, 미완료 작업 재배치, 심리적 완충 UX
2.5 보드 보기와 리스트 보기의 전환 맥락
  • 사용자가 어떤 보기 방식을 선택해야 할지 모를 수 있음
  • 보드 보기는 프로젝트 관리 도구처럼 보여 사용 기대가 달라질 수 있음
  • 개선 방향: 프로젝트 생성 시 추천 보기, 목적별 보기 예시, 전환 시 데이터 구조 설명
2.6 협업 기능의 포지셔닝
  • 개인 생산성 앱 인식이 강하고 팀 기능은 보조 기능처럼 느껴질 수 있음
  • 팀 협업에서는 권한, 리포트, 일정 의존성, 대규모 워크플로우가 부족해 보일 수 있음
  • 개선 방향: 개인용/팀용 사례 분리, 소규모 팀 협업 포지션 명확화
2.7 무료/유료 기능 경계
  • 리마인더, 캘린더 보기, 필터, 협업, 템플릿의 무료/유료 경계가 중요함
  • 사용하려는 순간 제한을 만나면 실망 가능
  • 개선 방향: 기능 설정 화면에서 사전 표시, 기능 맥락 안의 업그레이드 안내, 무료 대안 제시
2.8 알림 피로도
  • 마감일, 반복 작업, 팀 댓글, 여러 기기 동기화에서 알림이 많아질 수 있음
  • 작업 관리 앱이 스트레스 요인이 될 수 있음
  • 개선 방향: 알림 우선순위, 조용한 시간대, 중요 작업만 알림
2.9 빈 상태 화면
  • Inbox, Today, 프로젝트, 라벨, 필터 결과가 비어 있을 수 있음
  • 개선 방향: 다음 행동 제안, 예시 작업, 템플릿 추천, 기능 설명 연결
2.10 접근성
  • 우선순위 색상만으로 중요도를 구분하면 한계가 있음
  • 빠른 추가, 날짜 변경, 완료 처리 단축키 안내가 중요함
  • 화면 밀도 조절 옵션이 명확해야 함
2.11 차별점 표현
  • TickTick, Microsoft To Do, Google Tasks, Notion, Asana/Trello와 비교됨
  • 왜 Todoist를 선택해야 하는지 명확한 비교가 필요함
  • 개선 방향: 빠른 입력 + 자연어 날짜 + 프로젝트 구조화 강점 강조, 사용자 유형별 사용법, 비교표

  2. 2프로젝트, 라벨, 필터 개념 구분 강화
  3. 3고급 기능 발견성 개선
  4. 4무료/유료 기능 경계 명확화
  5. 5Today 과부하와 알림 피로도 완화
